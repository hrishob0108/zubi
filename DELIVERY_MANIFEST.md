## 🎓 INTERVIEW HIGHLIGHTS

**When interviewer asks:** "Tell me about this project"

**You can say:**
> "This is a full-stack React + Node.js application that enables real-time AI conversations with children. It features browser-native speech recognition, text-to-speech, and a tool-calling system where the AI can trigger UI actions like object highlighting and confetti animations.
>
> Frontend: React with hooks for state management, Vite for fast development, Tailwind for styling. Real-time speech handled with Web Speech API and SpeechSynthesis.
>
> Backend: Express server maintains conversation history per session, integrates with OpenAI API (or uses smart mock responses), handles tool calls.
>
> Special features: Automatic microphone activation after AI speaks, 60-second timer, modular component design, error recovery, works with or without API key. Production-ready with ~3,500 lines of clean code."

**When asked:** "What were the challenges?"
- Automatic microphone activation (500ms delay strategy)
- Tool call parsing and UI component triggering
- Memory management for long conversations
- Browser compatibility (Firefox lacks Web Speech API)
- Speech synthesis voice selection across platforms

**When asked:** "How would you improve it?"
- Multi-language support
- Analytics dashboard
- Different scene options
- Sound effects library
- Difficulty levels
- Achievement system
- User profiles
